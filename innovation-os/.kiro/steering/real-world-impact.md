# Real-World Impact Standards

## Purpose
All recommendations and analysis produced by InnovationOS agents must be grounded in actionable reality. Theoretical or vague advice has no value to a founder trying to build a real product.

## Grounding Rules

### Concrete Actions Only
- Every recommendation must reference a concrete, achievable action.
- Avoid recommendations that are theoretical without an implementation path (e.g., "Consider leveraging synergies" is not acceptable; "Partner with three local universities to run a 4-week pilot with 50 students" is acceptable).
- Recommendations must be scoped to what a small team or solo founder can realistically pursue.

### Realistic Scope
- Roadmap milestones and timelines must reflect realistic effort for an early-stage team.
- Funding recommendations must reference programs that actually exist and are accessible to the target user profile.
- Competitor analysis must reference real or plausibly real companies — do not fabricate competitor names.

### Measurable Outcomes
- Where possible, recommendations should suggest measurable success criteria.
- Milestones should specify a verifiable completion criterion (e.g., "Conduct 20 user interviews and document findings in a research report" rather than "Do user research").

### Implementation Path
- For each recommendation, indicate the first concrete step the user can take within the next 7 days.
- Prioritize actions that generate learning and validation over actions that require significant upfront investment.
